DK MEDIA PLAYER: APPROVED ORIGINAL CINEMA EMBLEM — CORRECTED ICON EXPORTS

All PNGs and favicon.ico in this archive use the EXACT APPROVED red-and-gold ДК cinema emblem with the filmstrip/play button. No alternate simplified logo has been substituted.

APPROVED_ORIGINAL_1254.png is the original approved master, unmodified.

For a high-resolution app icon, upload dk-media-player-512.png or dk-media-player-1024.png.
For iPhone, use dk-media-player-180.png; for a web manifest use 192 and 512.
For favicons, use favicon.ico and/or favicon-32.png. favicon.ico contains 16, 32, 48, 64, 128, and 256 pixel versions.

IMPORTANT: Fine filigree and other tiny details in the approved artwork cannot remain visibly distinct at 16x16 pixels. This is a limitation of 16-pixel raster icons, not an image-resolution defect. The 16-pixel version has been downsampled and sharpened using the ORIGINAL artwork. Browsers can display higher-resolution sizes for improved clarity.

These files are intended for the GitHub repo DK-Media-Player/assets/images/.

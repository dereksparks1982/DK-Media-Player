Using the web player

Play files on this device

Choose one or several media files. They play in your browser and are not uploaded. In DK Browser and other browsers with the File System Access API, the last opened file can be remembered across reloads. If permission expires, use Restore last file. Firefox uses a session-only picker.

Play remote video

Paste a direct, publicly reachable media URL. The server must permit streaming, and the file must use a codec your browser understands. GitHub Pages does not host or expose videos on your Linux computer.

Library and resume

Save direct URLs to the Library to reopen later. Watched positions and saved links are stored only in this browser. They do not automatically sync to your other devices.

Subtitles

Load your own WebVTT (.vtt) or SubRip (.srt) subtitle file for the currently playing video. Built-in subtitle tracks depend on the browser and media format.

Fullscreen and keyboard

Double-click the video to enter fullscreen; double-click again or press Esc to return to normal. A single click plays or pauses. Space or K: play/pause. Left and right arrows: jump five seconds. F: fullscreen. M: mute. Scroll over the player to adjust volume in 5% steps. Shortcuts do not interfere while you type in a field.

iPhone and iPad

Use Safari or another browser to select a local file or open a direct media URL. You can add this site to your Home Screen. iOS supports HLS streams natively; other codecs vary by device.

DK Media Player is free software. This web player runs independently in your browser, using video formats supported by that browser.
